# doc-extractor examples

Self-contained, runnable examples. Each folder covers one real task and contains its
input `data/`, any profile it needs, its scripts, a `README.md`, and the expected output in
`results/`. All documents are **fictional** and were generated by `make_demo_data.py`.
None are real bank records or downloaded papers.

| # | Example | Shows | Needs |
|---|---|---|---|
| 01 | [Quickstart](01_quickstart/) | smallest input for text, PDF table → records, CSV → records | core |
| 02 | [Research note](02_research_note/) | text and a results table from a scientific-style report | core |
| 03 | [Bank statement PDF](03_bank_statement_pdf/) | multi-page statement → normalized records; reconcile balances in Python | core |
| 04 | [Bank CSV export](04_bank_csv_export/) | `;` delimiter, cp1252 encoding, German headers → records | core |
| 05 | [Parquet and DuckDB](05_parquet_and_duckdb/) | export records to Parquet, analyse with SQL | `tabular`, `sql` extras |
| 06 | [Borderless invoice](06_borderless_invoice/) | tables without cell borders: why guessing fails, how `pdf.table_from_header` fixes it | core |
| 07 | [Compare with source](07_compare_with_source/) | HTML report: page image next to extracted tables, x-position ruler, for your own files | core |
| 08 | [Statement without lines](08_statement_without_lines/) | header-based table, `DD/MM` dates with the year from the statement period, totals check | core |

Run every command from the **repository root**, e.g.

```sh
doc-extractor extract examples/03_bank_statement_pdf/data/demo_statement.pdf --mode records \
  --profile-file examples/03_bank_statement_pdf/northwind_statement_pdf.yaml --to markdown
```

## Other files

| File | Purpose |
|---|---|
| `make_demo_data.py` | regenerates every `data/` file (needs `reportlab`, `dev` extra); `--results` also refreshes every `results/` file |
| `expected_results.py` | the documented command behind each `results/` file; `tests/test_examples.py` runs them all |

## Keeping examples correct

`python -m pytest tests/test_examples.py` runs every documented command, compares the
output with `results/`, and runs the Python scripts. After an intended change to output,
refresh the expected files and review the diff:

```sh
python examples/make_demo_data.py --results
```

## Your own documents

Do not add private documents here. Put them in `docs/private/` (git-ignored) and use
[example 07](07_compare_with_source/) to check the results.
